# Симулятор карт «Заставы»

Сайт: https://jaba-sys.github.io/zastava-sim/

Пробеги по карте от первого лица — та же физика, что в игре
[«Застава»](https://zastava.web.app): бег (Shift), прыжок, присед, подкат (бег + C).

- **Карты игры** — выбери в списке.
- **Своя карта** — «Открыть файл…» или перетащи `.zmap.json` из
  [редактора карт](https://jaba-sys.github.io/zastava-maps/) прямо на страницу.
  В редакторе есть кнопка **«Пробежать ▶»** — она открывает карту здесь сразу.
- **Секундомер**: от возрождения до точек A и B, отдельно для террористов и
  спецназа. Хорошая карта — когда спецназ успевает на свою точку чуть раньше.
- **V** — полёт сквозь стены (осмотреть карту сверху), **R** — заново,
  **ЛКМ** — стрелять по мишеням на базе врага и на точках.

## Файлы

| Файл | Что делает |
|------|-----------|
| `index.html`, `css/sim.css` | страница и оформление |
| `js/sim.js` | симулятор: загрузка карты, управление, секундомер, мишени |
| `js/game/physics.js` | физика — копия из игры |
| `js/game/maps/builder.js`, `fromdata.js` | постройка карты — копия из игры |
| `js/game/maps/editorfile.js` | чтение файла карты — копия из игры |
| `maps/*.zmap.json` | карты игры |

Страница собрана из модулей — открывается с сайта (GitHub Pages), а не
двойным щелчком по файлу.
